# Changelog

All notable changes to this documentation repository are recorded here.
This changelog tracks the public docs and examples, not the Vilix AI product
itself.

The format is loosely based on [Keep a Changelog](https://keepachangelog.com/).

## 0.1.3 - 2026-09-10

- Added remote MCP Registry metadata for `io.github.Appfairly/vilix`
- Added a manual, main-only Registry publish workflow using GitHub OIDC
- Pinned the publisher and checkout action, with validation and publication checks
- Registry metadata starts at version `1.0.0`; this docs release is `0.1.3`
  and neither version identifies the hosted Vilix product deployment

## 0.1.2 - 2026-09-10

- Migrated setup, dashboard, policy, and support links to vilix.ai
- Replaced retired SSE connection instructions with Streamable HTTP guidance
- Updated Claude, ChatGPT, Cursor, and Cascade guides from current vendor docs
- Added a Codex guide covering OAuth and environment-based API-key authentication
- Linked guides and examples directly from the README
- Clarified client requirements, tool approvals, and the retrieve/save call order
- Added a documentation VERSION file; this is not a hosted-product version

## 0.1.1

- Finalized licensing: MIT License for the documentation and example content
- Added UTM attribution to "get started" call-to-action links
- Repository now hosted under the Appfairly organization

## 0.1.0

- Initial public Vilix AI MCP docs repo
- Added setup guides and example workflows
- Added README landing page, security policy, contributing guide, and issue templates
