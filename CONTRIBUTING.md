# Contributing

Thanks for your interest in improving Vilix MCP's public documentation.

## What this repository is for

This repo is **mainly for docs, examples, and community feedback**. It is the
public developer-facing home for Vilix MCP — not the Vilix product source code.

The Vilix backend, production code, and infrastructure are **not** part of this
repository and are not open source.

## What we welcome

- **Documentation improvements** — clarity, accuracy, typos, broken links
- **Setup guides** — better or new instructions for MCP-compatible clients
- **Example workflows** — practical, real-world usage patterns
- **Bug reports** — issues with setup steps or documentation
- **Feature requests** — ideas for the Vilix MCP experience

## How to contribute

1. Open an issue first for anything non-trivial, so we can align on direction.
2. Fork the repo and create a branch for your change.
3. Keep documentation clear, concise, and accurate. Do not add unverified
   claims (for example, partnership or "trusted by" statements that are not
   confirmed).
4. **Never include secrets, tokens, private memories, or personal data** in
   contributions. See [SECURITY.md](SECURITY.md).
5. Open a pull request using the
   [pull request template](.github/PULL_REQUEST_TEMPLATE.md).

## Style

- Write for someone landing here from a search engine with no prior context.
- Prefer plain language over jargon; explain MCP terms on first use.
- Use real, verified links. Mark anything unconfirmed with a clear `TODO`.
